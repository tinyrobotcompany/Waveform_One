# Release notes

Published versions, notes and firmware downloads live in
[GitHub Releases](https://github.com/tinyrobotcompany/Waveform_One/releases).

Pending release notes are recorded in [.changeset](.changeset). On a successful
`main` build, CI combines new notes, applies the largest requested semantic-version
bump and publishes a release. This file links to that single release history;
CI does not create recursive changelog commits.
