Initial Waveform One firmware release: a microphone-driven, 24-band ESP32-S3
visualizer with improved response to quieter music, direct HUB75 panel wiring
documentation, LED and microphone diagnostics, and two standalone scrolling demos.

Add host unit-test hooks, firmware build checks, Codex PR review automation,
and versioned GitHub releases. The downloadable visualizer bundle is installed
over USB on the documented ESP32-S3 16 MB setup. Pi deployment and device OTA
updates are not included in this release.
