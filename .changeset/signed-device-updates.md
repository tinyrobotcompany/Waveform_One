Add signed internet-delivered application updates coordinated by the Pi, with an
Updates screen on the touchscreen and phone, offline dependency bundles, previous
release recovery, and an A/B USB firmware update protocol for ESP32-S3. Devices
need one-time signed-release provisioning and an ESP partition migration before
using updates. Routine updates require an explicit Install action and do not
replace the operating system, recovery agent, bootloader or partition table.
