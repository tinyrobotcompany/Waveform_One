Add opt-in session listening history to paired-phone Settings, with a 50-track RAM limit, deletion and JSON export. History is off after every restart and contains metadata, not audio. Discogs searches happen only when tapped. An optional desktop Last.fm bridge requires authorization and explicit confirmed export/submission; no automatic history upload is enabled. See docs/listening-history.md for retention, limitations and deletion.
